# Lumen: установка без Mac (Windows + iPhone)

## 1. Собрать приложение в облаке
1. Зарегистрируйся на github.com, создай новый репозиторий (New repository, Public).
2. Загрузи в него ВСЁ содержимое этой папки, включая скрытую папку .github (Add file → Upload files, перетащи папки).
   Если .github не загрузилась: Add file → Create new file, в имени файла напиши  .github/workflows/build.yml  и вставь туда содержимое build.yml.
3. Вкладка Actions → слева «Build IPA» → кнопка Run workflow.
4. Через 5–10 минут открой завершённый запуск, внизу в Artifacts скачай Lumen-ipa (это zip, внутри Lumen.ipa).
   Если запуск красный: открой его, скопируй текст ошибки и пришли мне.

## 2. Поставить на айфон
1. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, перезагрузить.
2. На Windows установи iTunes (с сайта Apple) и Sideloadly (sideloadly.io).
3. Подключи айфон кабелем, разреши доверие компьютеру.
4. В Sideloadly перетащи Lumen.ipa, введи Apple ID, нажми Start.
5. На айфоне: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
6. Раз в 7 дней приложение нужно переустановить так же (ограничение бесплатного Apple ID).

Видео можно кидать в приложение кнопкой «+» или через Файлы → На iPhone → Lumen.
